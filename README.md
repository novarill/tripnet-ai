# TripNet AI｜去趣 eSIM

本專案為 **2026 和泰 AI 黑客松**提案，主要用於整理 TripNet AI 的產品需求、系統架構、介面設計與開發規劃。

TripNet AI 以 **去趣 eSIM 智慧旅遊通訊服務** 為核心，結合 AI 智慧推薦與個人化服務，協助旅客在出國前選擇合適的 eSIM 方案，並提供購買、啟用及旅途中相關服務支援，打造更便利的跨境通訊體驗。

## 專案目錄結構

```text
tripnet-ai/

├── 架構圖/
│   ├── architecture.png

```

## 文件說明

### 1. 介面預覽

存放專案的使用者介面設計與畫面預覽，涵蓋 eSIM 方案推薦、方案比較、購買流程及旅途中服務支援等功能，供團隊參考系統的視覺呈現、功能配置及操作方式。

### 2. 架構圖

存放系統架構與開發規劃相關圖表。

| 檔案名稱 | 說明 |
| :--- | :--- |
| `architecture.png` | **系統架構圖**：呈現 AI 推薦系統、eSIM 服務模組、資料處理及各元件之間的關係。 |
| `workchart.png` | **工作規劃圖**：整理專案開發工作項目、執行流程與任務安排。 |

### 3. PRD.md

**產品需求文件（Product Requirements Document）**：整理專案背景、目標使用者、核心功能、使用情境及系統需求，作為後續介面設計與功能開發的依據。

### 4. README.md

專案說明文件，整理專案背景、目錄結構及各項文件用途，方便團隊成員快速了解專案內容。
